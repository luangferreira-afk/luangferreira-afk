# Luan Gasparotto Ferreira — Portfólio

Portfólio profissional em React + Vite + Tailwind, com layout responsivo, navegação por âncoras e conteúdo centralizado para edição.

## Onde editar

Abra `client/src/data/portfolio.ts`. Esse arquivo concentra nome, textos, e-mail, links, capacidades, projetos, estatísticas e trilha de aprendizado. Depois de salvar, rode `pnpm dev` para visualizar as alterações.

## Rodar localmente

```bash
pnpm install
pnpm dev
```

## Estrutura

- `client/src/data/portfolio.ts`: conteúdo editável
- `client/src/pages/Home.tsx`: estrutura das seções e interações
- `client/src/index.css`: identidade visual, responsividade e animações
